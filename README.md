# MARHAEN-2.0
MARHAEN 2.0 adalah custom skill Claude.ai yang menyempurnakan Marhaenisme Soekarno sebagai kerangka berpikir revolusioner untuk 2026–2076. Mampu menganalisis isu AI, krisis iklim, geopolitik, dan ekonomi digital melalui lensa Sosio-Nasionalisme Indonesia-sentris, menghasilkan diagnosis struktural dan solusi berbasis gotong royong. By CDCI.
